# The Uncomfortable Mirror

A source snapshot of a life-decisions companion app created with Emergent,
using Expo Router (React Native), FastAPI, MongoDB, and an Emergent-hosted
language-model integration.

## Snapshot status

These files were recovered from pasted source code. This is not a complete,
runnable clone of the original project. The snapshot does not contain the
database, the original credentials, or all project scaffolding and template
files. In particular, Expo configuration and dependency manifests, backend
dependencies, and imported template modules such as the error boundary and
query client are missing. Additional configuration or assets may also be
needed. The original implementation uses `emergentintegrations` and an
Emergent key; it cannot be assumed to work with a direct provider key without
changes.

The `.env` shown in the pasted source contained placeholder values and was not
included. Never commit real API keys, passwords, or other credentials.

This snapshot is intended to preserve the recovered source for later review,
not to imply that the application has been tested or is ready for deployment.
